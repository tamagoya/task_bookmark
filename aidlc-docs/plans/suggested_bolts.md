# Suggested Bolts（推奨ボルト） - タスクブックマーク Chrome 拡張

## 概要
本ドキュメントは、タスクブックマークChrome拡張機能の各Unitを実装するための短期反復サイクル（Bolts）を提案します。各Boltは、1-2週間で完了可能な範囲で、独立して価値を提供できる単位として定義します。

## Boltの定義
- **期間**: 1-2週間（10営業日）
- **スコープ**: 1-2つのUser Stories、または1つのUnitの部分実装
- **成果物**: 動作するコード、テスト、ドキュメント
- **価値**: 各Boltは独立して価値を提供し、デモ可能

## 実装順序とタイムライン

### Phase 1: 基盤構築（3週間）
1. **Bolt 1**: Chrome拡張基盤と認証（2週間）
2. **Bolt 2**: カレンダー初期化とAPI連携基盤（1週間）

### Phase 2: コア機能実装（4週間）
3. **Bolt 3**: タブ状態キャプチャ（1週間）- Bolt 1と並行可能
4. **Bolt 4**: 仕事状態の保存（2週間）
5. **Bolt 5**: 保存済み仕事一覧表示（1週間）

### Phase 3: 復元機能実装（3週間）
6. **Bolt 6**: 仕事状態の復元（2週間）
7. **Bolt 7**: 復元メタデータと前後関係（1週間）

### Phase 4: 拡張機能と最適化（3週間）
8. **Bolt 8**: URL編集機能（1週間）
9. **Bolt 9**: エラーハンドリングとUX改善（1週間）
10. **Bolt 10**: パフォーマンス最適化とテスト（2週間）

### 合計期間
**約13週間（約3ヶ月）**

## 並行開発の可能性

### 並行可能なBolt
- **Bolt 1とBolt 3**: 認証とタブキャプチャは独立しているため、並行開発可能
- **Bolt 5とBolt 6**: 一覧表示と復元機能は部分的に並行開発可能（UI部分）

### 依存関係の管理
- 各Boltの開始前に、依存するBoltの完了を確認
- モックを使用して、依存関係を緩和（例: Bolt 3はBolt 1のモックを使用可能）

---

## リスク管理

### 各Boltでのリスク対応
- 各Boltの開始前に、関連するリスクを確認
- リスクが実現した場合の軽減策を準備
- 必要に応じて、Boltのスコープを調整

### スケジュール管理
- 各Boltの完了時に、次のBoltの開始を確認
- 遅延が発生した場合、優先順位を再評価
- MVP機能（Bolt 1-6）を優先

## MVP（Minimum Viable Product）の定義

### MVPに含まれるBolt
- Bolt 1: Chrome拡張基盤と認証
- Bolt 2: カレンダー初期化とAPI連携基盤
- Bolt 3: タブ状態キャプチャ
- Bolt 4: 仕事状態の保存
- Bolt 5: 保存済み仕事一覧表示
- Bolt 6: 仕事状態の復元

### MVP期間
**約10週間（約2.5ヶ月）**

### MVP後の拡張
- Bolt 7-10は、MVPリリース後の拡張機能として実装
